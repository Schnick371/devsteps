## Purpose

DevSteps bridges the gap between AI-assisted development and structured project management. It provides:

- **Work item traceability** — every commit, doc, and code change links to a backlog item
- **AI orchestration** — Spider Web multi-agent dispatch built on GitHub Copilot
- **Developer experience** — MCP tools, CLI, and VS Code extension for seamless workflow

## Target Audience

- Software developers using GitHub Copilot for coding
- Tech leads managing feature backlogs and sprint planning
- DevOps engineers integrating AI tooling into CI/CD workflows

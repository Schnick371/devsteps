# DevSteps Handbook

DevSteps is an AI-powered task tracking and traceability system for software projects. This handbook provides comprehensive documentation organized by functional area — from installation and core concepts to deep reference material for every tool, agent, and workflow.

## How to Use This Handbook

The handbook is structured in five levels following the **Siemens documentation principle**: functional areas at Level 1, with Diataxis quadrants (Tutorial, How-to, Reference, Explanation) as sub-chapters within each area. This ensures all documentation for a topic lives together regardless of its type.

| Level | Role | Example |
|-------|------|---------|
| L1 | Functional area | MCP Tools |
| L2 | Chapter within area | Work Item CRUD Tools |
| L3 | Specific topic | `mcp_devsteps_add` reference |
| L4 | Deep sub-topic | Parameter tables & schemas |

## Functional Areas

1. **Introduction & Overview** — What is DevSteps, product architecture, changelog
2. **Fundamentals** — Core concepts, data model, status lifecycle, relationship types
3. **AI & Copilot Integration** — Spider Web dispatch, agent roles, entry points, how-to guides
4. **VS Code Extension** — Activity bar, TreeView, Kanban dashboard, how-to guides
5. **DevSteps MCP Tools** — Full tool reference with parameters, schemas, examples
6. **DevSteps CLI** — Command reference, installation, daily workflow guides
7. **Documentation System** — Doc items, BOM structure, Diataxis framework, assembly workflow

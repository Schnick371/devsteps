Part of the dual-write architecture in STORY-221. The JSON shadow at .devsteps/index/docs-map-positions.json is a flat array: [{ arch_id: string, doc_id: string | null, title: string, parent_arch_id: string | null, depth: number, devsteps_items: string[] }]. Written atomically by writeDocsMap() alongside docs-map.yaml. Enables O(1) cross-reference queries ("which DevSteps items link to BOM level 2 nodes?") without YAML tree traversal. First-time migration: manually-created docs-map.yaml without a shadow requires one devsteps docs rebuild CLI command (backfill). This task is partially included in STORY-221 scope; created as sub-task for tracking purposes.

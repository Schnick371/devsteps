Nach Hinzufügen des `doc`-ItemType werden über `devsteps list --type doc` bzw. `mcp_devsteps_list` mit `filter.type: 'doc'` keine Items zurückgegeben, obwohl DOC-001 bis DOC-053 existieren.

**Root Cause:** Staler Binary / nicht aktuell gebuildeter MCP-Server. Das `doc`-ItemType wurde in `packages/shared` ergänzt, aber der dist-Build der MCP-Server-Binaries (npm published + Extension-Bundle) ist veraltet.

**Fix:** `npm run build` + MCP-Server-Neustart behebt das Problem im lokalen Setup. Für published Server: neuer Release nötig (nach BUG-085 Fix).

**Reproschritt:** Mit published `@schnick371/devsteps-mcp-server` via `mcp_devsteps_list` `type=doc` aufrufen → 0 Ergebnisse.

## Bug Description

`buildFlatSectionNodes()` in `packages/extension/src/treeView/utils/flatViewBuilder.ts` reads `config.methodology` to determine whether to show Scrum/Waterfall sections:

```typescript
if (scrumItems.length > 0 || config.methodology !== 'waterfall') { ... }
if (waterfallItems.length > 0 || config.methodology !== 'scrum') { ... }
```

But the actual `.devsteps/config.json` structure nests methodology under `settings`:
```json
{ "settings": { "methodology": "hybrid" } }
```

So `config.methodology` is always `undefined`. Both conditions `undefined !== 'waterfall'` and `undefined !== 'scrum'` are always `true` — both sections show unconditionally regardless of project type. A Scrum-only project shows an empty "Waterfall Items" section; a Waterfall-only project shows an empty "Scrum Items" section.

## Fix
Change `config.methodology` → `config.settings?.methodology` in both conditions.

Pre-extract: `const methodology = config.settings?.methodology ?? 'hybrid';`

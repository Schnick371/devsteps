Spider Web dispatch silently rejects DOC item IDs. The regex patterns in packages/shared/src/schemas/cbp-mandate.ts:72 (item_ids field) and packages/shared/src/schemas/analysis.ts:94 (task_id field) only accept EPIC|STORY|TASK|REQ|FEAT|BUG|SPIKE|TEST prefixes. When a DOC work item is dispatched through the Spider Web (its ID passed as item_id or task_id), Zod throws a ZodError at runtime without surfacing a meaningful error to the caller. This means any DOC work item in Spider Web dispatch fails silently until this is fixed. Fix: add DOC to both regex patterns. This fix is independent of Phase 1 and can be shipped standalone.

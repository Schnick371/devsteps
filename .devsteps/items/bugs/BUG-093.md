DashboardPanel.postSpiderEvent() (implemented as part of STORY-206) sends { command: 'spiderEvent', event } via webview.postMessage(), but the inline webview script has no message event listener for this command. Spider events from hooks are silently dropped. Fix: add window.addEventListener('message', (e) => { if (e.data.command === 'spiderEvent') { /* store + visualise */ } }) to the inline script in dashboardPanel.ts. Minimum viable implementation: store the last event, log to console. STORY-206 method signature MUST remain unchanged.

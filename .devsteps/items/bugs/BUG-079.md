# Bug: Write-Order in update.ts

In `packages/shared/src/core/update.ts` wird die Metadaten-JSON-Datei BEVOR die MD-Datei geschrieben:

```typescript
// AKTUELL (FALSCH):
writeFileSync(metadataPath, JSON.stringify(updatedMetadata, null, 2));  // JSON zuerst
writeFileSync(descriptionPath, normalizeMarkdown(args.description));    // MD danach
```

Wenn `description_hash` in Rec 2 (STORY für 3 JSON-Felder) implementiert wird, muss der Hash aus dem FINALEN normalizeMarkdown()-Ergebnis berechnet werden. Die aktuelle Reihenfolge würde den Hash des alten MD-Inhalts speichern.

## Fix:
1. MD-Datei schreiben (normalizeMarkdown)
2. Hash aus geschriebener MD-Datei berechnen
3. Hash in updatedMetadata setzen
4. JSON-Datei schreiben

Betroffen: packages/shared/src/core/update.ts (~Line 130-140)

Blocking: Implementierung von description_hash (Option C)

## Ergebnis

Write-Order korrigiert: MD wird jetzt VOR JSON geschrieben. Alle 461 Tests bestanden. Commit committed.

## Bug Description

`getItemMethodology()` in `packages/extension/src/treeView/utils/methodologyDetector.ts`
performs recursive parent traversal for shared item types (task, bug, test). It has NO
visited-set guard. A single self-referential link (e.g., BUG-032 implements BUG-032) or
a circular chain causes infinite recursion → stack overflow → the `getFlatRootNodes()`
try/catch silently swallows the error → flat view returns empty [].

## Root trigger
BUG-032.json had `implements: ["BUG-032"]` — a self-loop introduced by a data management
error. This went undetected for months and silently broke the flat view once 58 DOC items
were added (all new items caused a full re-scan).

## Fix
Add `visited = new Set<string>()` parameter to `getItemMethodology()`:
```typescript
export function getItemMethodology(
  item: WorkItem,
  allItems: Map<string, WorkItem>,
  visited: Set<string> = new Set()
): 'scrum' | 'waterfall' | 'cross-cutting' {
  if (visited.has(item.id)) return 'scrum'; // cycle detected — fallback
  visited.add(item.id);
  
  // ... existing logic, pass visited to recursive calls
  return getItemMethodology(parentItem, allItems, visited);
}
```

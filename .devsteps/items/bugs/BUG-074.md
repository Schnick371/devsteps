`packages/extension/package.json` is missing `"onLanguage:markdown"` from `activationEvents`. As a result, all Phase C markdown contributions (`contributes.markdown.markdownItPlugins: true` and `contributes.markdown.previewScripts: ["./dist/preview/depthSlider.js"]`) are silently NOT activated when a user opens a `.md` file — unless the file happens to exist in a workspace where another DevSteps activationEvent has already fired.

**Fix required:**
1. Add `"onLanguage:markdown"` to `activationEvents` array in `packages/extension/package.json`
2. Add `hasDevStepsRoot()` guard check in `embedPlugin.ts` at plugin registration time (prevents the extension from activating and doing work in non-DevSteps workspaces)
3. The utility function `hasDevStepsRoot(workspaceFolders)` should live in a shared `packages/extension/src/utils/workspace.ts`

[Update 2026-04-03] Format updated: docs-map.json (not .yaml). See STORY-233 + ADR-007.

New MCP tool (CANNOT reuse mcp_devsteps_list — different data source: JSON adjacency list vs JSON index). Tool signature: mcp_devsteps_doc_depth_query(bom_position_prefix?: string, max_depth?: number): { nodes: DocsMapNode[], total_nodes: number }. Reads docs-map.json via readDocsMap() from docs-map.ts. Traverses the flat adjacency list, filtering by bom_position_prefix if provided (e.g., "ARCH-001" returns that node and all children). Returns nodes flattened to max_depth (default: full tree). No coupling to list.ts or any JSON index. Requires STORY-233 (docs-map.json migration) and STORY-221.
